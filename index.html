MÉTHODE T.R.M.

Deux niveaux, zéro confusion.

01 · Existant : murs, cotes, ouvertures et objets observés.
02 · Projet : meubles et aménagements suggérés, distincts du relevé.
03 · Contrôle : les dimensions contradictoires sont signalées et non masquées.

03 — INTELLIGENCE ARTIFICIELLE

Compréhension du chantier

Gemini reçoit tes images et ton explication. L'analyse distingue les éléments réellement observés des propositions d'aménagement. En cas d'indisponibilité, un autre modèle compatible est essayé.

Clé, confidentialité et limites

La clé est mémorisée dans le stockage local de ce navigateur, jamais dans GitHub. Ce stockage n'est pas un coffre-fort sécurisé : sur un site public, une architecture avec serveur serait préférable. Les photos sont envoyées à Google lors de l'analyse. Les cotes doivent être vérifiées avant travaux.

05 — PROJET D'AMÉNAGEMENT

Vue 3D liée au plan

Volumes schématiques générés depuis les mêmes coordonnées que le plan 2D. Les meubles proposés ne constituent pas un relevé de l'existant.

La vue 3D apparaîtra après l'analyse.

06 — ARCHIVES

Ton dossier chantier

La sauvegarde contient les cotes, les équipements, le texte explicatif et les photos importées. Conserve le fichier sur ton téléphone ou dans ton Drive.

La clé API n'est jamais incluse dans le dossier exporté.
